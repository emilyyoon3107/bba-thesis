# Data Instructions for FEC contributions

The raw files are from the [FEC official website](https://www.fec.gov/data/browse-data/?tab=bulk-data). 

## Individual Contributions
- Category: Transaction files > Contributions by individuals
- Range: Header file, 1995-1996 to 2021-2022
- Note: Original downloads from the website come in zip folders titled `indiv{YY}.zip`, containing `itcont.txt`. The files are extracted and renamed `itcont{YYYY}.txt`
- File names (as called in the code):
```
    indiv_header_file.csv
    itcont1996.txt
    itcont1998.txt
    itcont2000.txt
    itcont2002.txt
    itcont2004.txt
    itcont2006.txt
    itcont2008.txt
    itcont2010.txt
    itcont2012.txt
    itcont2014.txt
    itcont2016.txt
    itcont2018.txt
    itcont2020.txt
    itcont2022.txt
```
